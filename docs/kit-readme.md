# Wayfare IDE kit

Everything your AI IDE needs to build the Wayfare app.

1. Make an empty folder called `wayfare` and unzip this kit into it.
2. Open the folder in Cursor, Claude Code, Windsurf or Codex.
3. Say: **"Read PROMPT.md and every file it points to, then start Phase 0. Stop and show me after each phase."**

| Folder | Contents |
|---|---|
| `PROMPT.md` | The full build prompt (product, design system, screens, logic, data, API, offline, tests, phases, demo script) |
| `.claude/skills/landing-page-design/` | Design skill from github.com/elayadesign/ai-design-skills (MIT, licence included) |
| `assets/brand/` | `tokens.css` (Tailwind v4 brand tokens), pin, logo and favicon SVGs |
| `assets/illustrations/` | Skyline and EV charging art cut from the poster, cream and transparent |
| `reference/` | Brand sheet, full poster, poster sections, first app mockup |
| `reference/inspiration/` | ssgoi.dev, glass.samasante.com, 60fps.design, 21st.dev, withanimation.app, accent colour lesson |

Before the demo, work through the "Verify before the demo" list the agent writes into the project README.
